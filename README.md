# A Voice-Assisted Smart Device for Visually Impaired People

Official code repository for our IEEE BECITHCON 2025 conference paper.

## Publication

**Title:** A Voice-Assisted Smart Device for the Visually Impaired People: Leveraging AI Vision, Object Detection, and GPS-Based Navigation

**Authors:** Shithi Datta et al.

**Conference:** IEEE BECITHCON 2025

**DOI:** [10.1109/BECITHCON69222.2025.11504107](https://doi.org/10.1109/BECITHCON69222.2025.11504107)

## Overview

This project presents a voice-assisted smart device designed to support visually impaired people through AI-based object detection, visual scene understanding, text extraction, and GPS-based navigation assistance.

## Technologies

- YOLOv8 for object detection
- Gemini API for AI-based visual assistance
- GPS-based location information
- Telegram integration

## Repository Structure

- `code/` — Implementation source code
- `requirements.txt` — Python dependencies, if applicable

## Usage

Review the source files and install the required dependencies before running the code. Configure any required API credentials securely using environment variables.
